GUIDE

사이트 상세 도움말

처음 방문해도 바로 사용할 수 있도록 찾기부터 읽기·기록·공유까지 순서대로 안내합니다.

1. 작품 찾기

메인에서 제목·작가를 검색하고 CP, 작품형태, 상태, 출처 필터와 정렬을 함께 사용할 수 있어요. 한글 입력 중에는 조합이 끝난 뒤 결과를 갱신해 모바일에서도 검색 입력이 끊기지 않도록 처리합니다. 외국어 작가명·작품명은 운영자가 등록한 한글 표기나 다른 검색 별칭으로도 찾을 수 있으며, 별칭 자체는 작품 목록에 표시되지 않아요. 모바일에서는 정렬과 보기 방식도 필터 패널 안에서 선택할 수 있고, 현재 선택값은 메인 필터 버튼에서 함께 확인할 수 있어요. 초기화를 누르면 정렬도 제목순으로 돌아갑니다. TXT와 POSTYPE 콘텐츠가 함께 표시되며, TXT는 사이트 뷰어에서 읽고 POSTYPE은 등록된 원문으로 이동합니다.

2. TXT 뷰어 · 읽기 설정

스크롤/페이지 모드, 글꼴, 글자 크기, 줄간격, 본문 좌우 여백(좁게/기본/넓게), 다크모드를 설정할 수 있어요. 지원 기기에서는 화면 켜짐 유지를 켜 뷰어가 열린 동안 화면 자동 꺼짐을 막을 수 있으며, 뷰어를 닫거나 앱·브라우저가 백그라운드로 가면 화면 유지도 해제됩니다. 다크모드 변경 시 지원되는 설치형 웹앱의 상태바·앱 창 테마 색상도 함께 맞춰집니다. 본문은 문단 첫 줄을 약 1글자 들여써 읽기 편하게 표시합니다. 현재 페이지/전체 페이지와 진행률을 확인할 수 있고, 페이지·진행 표시를 누르면 빠른 이동 슬라이더로 원하는 위치를 바로 찾을 수 있습니다. PC 페이지 모드에서는 ←/→ 또는 Page Up/Page Down 키로 앞뒤 페이지를 넘길 수 있으며, 검색창·메모 등 입력 중에는 페이지 이동 단축키가 작동하지 않습니다.

3. 본문 검색 · 원문 이동

뷰어의 검색에서 현재 작품 본문을 검색하면 결과 위치와 앞뒤 문맥이 표시됩니다. 결과를 누르면 해당 문장이 화면 중앙 부근에 오도록 이동하며, 스크롤/페이지 모드 모두 사용할 수 있어요. PC에서는 뷰어가 열린 상태에서 Ctrl+F, Mac에서는 Command+F를 누르면 작품 내 검색창을 바로 열 수 있습니다.

4. 이어보기 · 최근 본 작품

로그인 상태로 읽은 TXT의 위치가 저장되어 다시 열 때 이어볼 수 있어요. 이어보기 안내는 뷰어를 열면 먼저 표시되며, 최근 본 작품은 내 정보에서 다시 찾을 수 있습니다.

5. 내 정보

로그인하면 북마크 · 최근 본 작품 · 좋아요 · 내 서재를 한곳에서 관리할 수 있어요. 북마크/최근 본 작품/좋아요에서 작품을 열었다가 뷰어를 닫아도 보던 탭과 목록 위치가 그대로 유지됩니다. 북마크 저장 중 네트워크 오류가 발생하면 저장된 것처럼 남겨두지 않고 이전 상태로 되돌린 뒤 안내합니다.

6. 내 서재 · 문장 · 메모

내 서재에서는 저장 기록과 이 브라우저의 오프라인 저장 작품을 나눠 볼 수 있어요. 오프라인 저장 보기에는 현재 실제로 본문이 저장된 TXT와 개수가 표시되며 온라인 상태에서도 확인할 수 있습니다. 작품별 저장 기록에서는 전체/문장/메모 탭으로 구분해 볼 수 있고, 원문 보기를 누르면 저장했던 위치로 이동합니다. 파일이 교체되어 예전 작품 ID가 사라진 경우에도 제목·작성자로 원본을 다시 찾되, 같은 후보가 여러 개면 임의의 작품으로 이동하지 않고 안내합니다. 뷰어를 닫으면 보던 작품의 내 서재 상세화면으로 돌아옵니다.

TXT에서 문장을 선택하면 공유와 메모 버튼이 나타납니다. 공유에서는 문장 이미지 제작·문장 저장을, 메모에서는 선택한 문장에 개인 기록을 남길 수 있고, 내 서재에서 저장한 메모를 다시 수정하거나 삭제할 수 있어요. TXT의 같은 작품·같은 위치에서 같은 문장을 다시 저장하면 새 중복 기록을 만들지 않습니다. POSTYPE 직접 입력도 같은 제목·작성자의 동일 문장을 다시 저장하면 기존 저장 문장을 사용합니다.

7. 문장 저장 · 이미지 · 피드

마음에 드는 문장을 저장하고 테마·비율·글꼴 등을 조절해 카드 이미지로 만들 수 있어요. 저장 문장의 피드 공유 토글을 켜면 문장 피드에 공개되며 기본값은 비공개입니다. 피드에서는 최신순/좋아요순으로 공개 문장을 둘러볼 수 있고, TXT 문장의 작품 열기를 누르면 저장 당시 원문 위치가 여전히 유효한 경우 그 위치로 바로 이동합니다. 위치가 바뀐 경우에는 문장이 원문에서 하나만 확인될 때 안전하게 다시 찾아 이동하며, 원문이 수정되었거나 같은 문장이 여러 번 나와 정확한 위치를 특정할 수 없으면 작품 처음에서 열고 안내합니다.

8. 로그인 없이도 사용할 수 있나요?

검색·필터·정렬, TXT 읽기, POSTYPE 원문 이동, 문장 피드 열람 등 기본 기능은 로그인 없이 사용할 수 있어요. 로그인하면 이어보기 동기화, 북마크, 최근 조회, 좋아요, 내 서재처럼 계정에 기록되는 기능을 사용할 수 있습니다.

9. 문의 · 오류 · 계정 문의

? 도움말 → 익명 의견에서 로그인 없이 문의·오류·기능 제안을 보낼 수 있어요. 비밀번호를 잊었다면 로그인 화면의 비밀번호를 잊으셨나요?를 눌러 계정 문의를 열고 계정 아이디와 답변 받을 연락수단을 남겨 주세요. 관리자가 계정 아이디와 문의 내용의 최근 열람·북마크 등 이용 기록을 대조해 본인 확인이 가능한 경우에만 비밀번호를 초기화해 임시 비밀번호를 전달합니다. 연락수단만으로는 본인 확인하지 않습니다. 일반 의견은 계정 정보를 요구하지 않으며, 계정 문의에만 사용자가 직접 입력한 계정 아이디와 연락수단이 저장됩니다. 오류라면 하단의 문제 신고 정보 복사로 진단정보를 함께 전달할 수 있으며 비밀번호나 인증 토큰 값 자체는 포함하지 않습니다.

10. 개인정보 · 기록 삭제

계정과 독서 기록, 이용 통계 등 처리 항목은 화면 하단 개인정보 안내에서 확인할 수 있어요. 계정·관련 기록 삭제가 필요하면 운영자에게 요청해 주세요.

11. 화면이 이상하거나 최신 내용이 안 보일 때

먼저 새로고침하고 필터·정렬 상태를 확인해 주세요. 문제가 계속되면 익명 의견으로 증상과 재현 방법을 보내 주세요.

12. 홈 화면에 앱처럼 추가하기

지원 브라우저에서는 브라우저 메뉴의 앱 설치 또는 홈 화면에 추가를 이용해 셩냥책을 홈 화면에서 바로 열 수 있어요. Android에서는 Chrome·삼성 인터넷의 설치/홈 화면 추가 메뉴를, iPhone·iPad에서는 공유 메뉴의 홈 화면 추가를 이용하세요. 별도의 설치 안내 팝업은 표시하지 않으며, 설치하지 않아도 기존 웹 이용 방식은 그대로입니다. 지원 브라우저에서 온라인으로 열어본 TXT 본문은 자동 저장되어, 이미 열린 사이트 화면에서 연결이 끊겨도 다시 읽을 수 있어요. 저장된 작품은 메인 목록·카드와 내 정보 → 내 서재 → 오프라인 저장에서 확인할 수 있으며, 개별·선택·전체 삭제로 이 기기의 저장 본문만 정리할 수 있습니다. 사이트 새로 열기·목록 갱신·계정 동기화에는 연결이 필요합니다. 오프라인 저장 화면에서는 현재 사용량을 간단한 막대로 확인할 수 있고, ? 버튼에서 임시 저장·자동 정리 안내를 볼 수 있어요. 최근 사용한 최대 40개·총 32MiB를 보관하며 8MiB를 넘는 본문이나 저장공간 부족 시에는 저장되지 않을 수 있어요. 서버의 삭제 응답 또는 최신 목록에서 사라진 작품은 저장 본문과 화면 표시를 함께 정리합니다.

개인정보 안내

서비스 제공과 개인 독서 기록 동기화에 필요한 범위에서 정보를 처리합니다.

1. 계정 · 개인 독서 기록 회원가입 시 계정 아이디와 비밀번호를 처리합니다. 비밀번호 원문은 저장하지 않고 salt가 적용된 해시 형태로 저장합니다. 로그인 후에는 이어보기 진도, 북마크, 최근 조회·읽음·다운로드 시각, 작품 좋아요, 저장 문장, 개인 메모와 원문 위치 정보가 계정에 연결되어 저장될 수 있습니다.
2. 이용 통계 · 접속 환경 서비스 개선과 성능·오류 점검을 위해 브라우저에 생성한 방문 식별자와 세션 식별자, 접속 일시, 페이지·작품 열람 횟수, 검색 횟수, 화면 활성 시간, 기기 유형, 브라우저 종류, 유입 유형·참조 호스트, 앱 버전과 로딩·뷰어 성능 정보 등을 저장합니다. 로그인 상태에서는 통계 세션에 계정 아이디가 연결될 수 있으며, 애플리케이션 통계 DB에는 IP 주소를 별도 저장하지 않습니다.
3. 공개되는 정보 저장 문장은 기본적으로 개인 기록입니다. 사용자가 직접 피드 공유를 켠 경우에만 해당 문장과 작품명·작성자 정보가 공개 문장 피드에 표시됩니다. 계정 아이디는 공개 피드에 표시하지 않습니다.
4. 익명 의견 · 계정 문의 · 오류 진단 일반 의견은 계정 아이디나 로그인 정보를 요구하지 않으며, 작성 내용과 카테고리, 현재 페이지·사이트 버전, 기기 화면 크기·플랫폼·브라우저 정보, 현재 필터·검색·열린 작품 등 오류 확인용 진단정보가 함께 저장될 수 있습니다. 계정 문의를 선택한 경우에만 복구 처리를 위해 사용자가 직접 입력한 계정 아이디와 답변 받을 연락수단을 저장하며, 본인 확인을 위해 문의 내용에 사용자가 직접 적은 최근 열람·북마크 등 이용 기록을 운영자가 계정 기록과 대조할 수 있습니다. 연락수단 자체는 본인 확인 수단으로 간주하지 않으며 오류 진단정보는 저장하지 않습니다. 자동 입력 방지를 위해 Cloudflare Turnstile을 사용합니다.
5. 쿠키 · 브라우저 저장소 자동 로그인·세션 유지와 화면/뷰어 설정, 방문 통계 식별 등을 위해 쿠키와 localStorage·sessionStorage를 사용합니다. 브라우저 저장 데이터를 삭제하면 자동 로그인이나 일부 개인 설정이 초기화될 수 있습니다.
6. 이용 목적 · 처리 환경 수집된 정보는 로그인과 계정 기능 제공, 독서 기록 동기화, 내 서재·북마크·좋아요 제공, 이용 현황 분석, 오류·성능·부하 점검과 서비스 운영을 위해 사용합니다. 사이트는 Cloudflare Pages/Workers/D1/KV 등 Cloudflare 인프라를 이용해 운영됩니다.
7. 보관 · 삭제 요청 계정 및 계정에 연결된 독서 기록은 서비스 운영 중 보관될 수 있으며, 삭제 요청이 확인되면 계정·세션·독서 기록·저장 문장·메모·좋아요·공유/피드 반응과 계정에 연결된 이용 통계 기록을 삭제합니다. 해당 계정 아이디로 접수된 계정 문의의 아이디·연락수단도 함께 삭제합니다. 일반 익명 의견처럼 계정과 연결되지 않은 기록은 계정 삭제만으로 자동 식별·삭제되지 않을 수 있습니다. 삭제를 원하면 운영자에게 요청해 주세요.
