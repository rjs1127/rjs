# Google Drive Archive Site — Change Log

이 README는 패치 버전별 변경사항을 누적 기록합니다.

## v6.4

### 수정
- 관리자 ZIP 배포 서버가 루트 `README.md`를 허용하지 않던 문제 수정
- 정상 형식으로 파싱되는 Google Drive 파일명은 수동 수정값보다 항상 우선하도록 변경
- 정상 파일에 남아 있는 오래된 KV override가 있어도 사용자 화면에서는 적용하지 않도록 개선
- `Drive 다시 읽기` 시 정상 파일에 연결된 기존 수동 override를 KV에서 자동 제거
- 이전 Drive 파일명과 현재 파일명을 비교하여 파일명 변경 여부를 동기화 결과에 기록
- 관리자 `수정 완료` 개수는 실제로 유효한 수동 수정값만 계산하도록 보정

### 파일명 우선순위
1. 현재 Google Drive 파일명이 정상 형식이면 Drive의 제목/작성자 사용
2. 현재 Drive 파일명이 비정상인 경우에만 관리자 수동 수정값 사용
3. 수동 수정값도 없으면 원본 파일명 기반 임시 정보 사용

## 패치 배포 원칙

앞으로 각 패치 ZIP에는 다음을 포함합니다.

- 실제 변경된 소스 파일
- `README.md` 변경 이력

다음 파일은 사용자가 명시적으로 요청하지 않는 한 패치 ZIP에 포함하지 않습니다.

- `wrangler.toml`
- `.env`, `.dev.vars`
- `.gitignore`
- 서비스 계정 / 토큰 / 인증정보 관련 파일
- 기타 Cloudflare 배포 설정 파일
