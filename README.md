## v6.37

### TXT 다운로드를 Google Drive 직접 다운로드로 변경
- 다운로드 버튼이 더 이상 Cloudflare `/api/content?download=1`을 거치지 않음
- 각 TXT 파일의 Google Drive 파일 ID를 사용해 `drive.google.com/uc?export=download&id=...` 링크로 직접 연결
- 리스트형 / 카드형 / 뷰어 상단 다운로드 버튼 UI는 그대로 유지
- Google Drive가 확인 페이지를 띄우는 경우에도 아카이브 화면을 잃지 않도록 새 탭에서 열도록 처리

### 서버 사용량 절감
- TXT 다운로드 시 Cloudflare Function 실행 없음
- 다운로드 시 KV / D1 접근 없음
- 다운로드 파일 전송을 Cloudflare가 중계하지 않음
- Google Drive에서 사용자 브라우저로 직접 전달
- 기존 본문 읽기 `/api/content`는 이전 구조 그대로 유지

### 다운로드 프록시 제거
- v6.36에서 `functions/api/content.js`에 추가했던 `download=1` 분기 제거
- 기존 본문 읽기/캐시용 API 코드로 복원

## v6.36

### TXT 원본 다운로드
- Google Drive TXT 작품에 다운로드 아이콘 추가
- 리스트형에서는 제목 영역 우측에 다운로드 아이콘 표시
- 카드형에서는 우측 하단에 다운로드 아이콘 표시
- 뷰어 상단에도 `다운로드` 버튼 추가
- 다운로드 아이콘 클릭 시 본문 뷰어를 열지 않고 바로 TXT 파일 다운로드
- 모바일에서는 아이콘 중심의 컴팩트 버튼으로 표시
- 다크모드 전용 버튼 색상도 함께 적용

### 다운로드 방식
- 브라우저의 Google Drive 공개 권한에 직접 의존하지 않고 기존 서비스 계정 연결을 사용
- `/api/content?download=1` 요청 시 아카이브 내부 TXT 파일인지 검증한 뒤 Google Drive 원본 파일을 내려받음
- `Content-Disposition: attachment`로 원래 TXT 파일명 그대로 저장
- 기존 본문 읽기/KV 캐시 로직에는 영향 없음

## v6.35

### 모달 배경 스크롤 차단
- 로그인 / 회원가입 / 도움말 / 북마크 / 최근 조회 / 계정 설정 모달이 열린 동안 뒤 메인 화면 스크롤 완전 차단
- PC와 모바일 모두 현재 페이지 위치를 고정한 뒤 모달 종료 시 원래 위치로 정확히 복귀
- 스크롤바가 사라지며 화면이 좌우로 흔들리지 않도록 scrollbar gap 보정
- 모달 내부 스크롤이 끝났을 때 뒤 페이지로 스크롤이 이어지는 scroll chaining 방지

### 모달 전환 안정화
- 도움말→로그인, 로그인→회원가입처럼 모달을 전환할 때 배경 잠금이 순간 해제되지 않도록 개선
- 동시에 여러 simple modal이 겹쳐 열리지 않도록 항상 하나만 활성화
- 바깥 배경 클릭 및 ESC 닫기 동작은 기존대로 유지

### 키보드 / 접근성 개선
- 모달이 열리면 뒤 메인 화면과 뷰어를 inert 처리하여 키보드/스크린리더가 배경 요소로 이동하지 않도록 개선
- Tab / Shift+Tab 포커스를 열린 모달 내부에 가둠
- 모달을 닫으면 열기 전에 사용하던 버튼으로 포커스 복귀
- 키보드 포커스 링을 명확하게 표시

### 모바일 모달 개선
- 모바일 주소창 높이가 변해도 모달이 화면 밖으로 밀리지 않도록 100dvh 기준 최대 높이 적용
- safe-area 여백 반영
- 모달 자체 스크롤바를 라이트/다크모드에 맞게 정리

### 서버 사용량
- 전부 브라우저 UI 동작 개선으로 D1 / KV / Google Drive API 사용량 증가 없음

### 모바일 컴팩트 헤더 수정
- 모바일 컴팩트 모드를 `로고 아이콘 / 검색창 / 계정 버튼` 3영역으로 재배치
- 컴팩트 상태에서는 북마크 / 최근조회 / 도움말 / 회원가입 버튼을 숨겨 검색창과 계정 버튼 겹침 방지

- 계정 모달에 `본문 간격 좁게 / 기본 / 넓게` 설정 추가
- 설정은 브라우저 localStorage에 저장되어 같은 기기에서 유지
- 서버/D1에는 저장하지 않으므로 추가 서버 사용량 없음
- 다크모드는 메인 화면, 목록, 모달, 뷰어 전반에 적용

## v6.31

### 목록 북마크 표시
- 리스트형 목록의 제목 영역 맨 오른쪽에 북마크된 작품만 북마크 아이콘 표시
- 기존 로그인 시 내려받은 유저 라이브러리 데이터로 표시하므로 추가 서버 요청 없음
- 모바일에서도 제목 폭을 침범하지 않도록 아이콘 크기 축소

### 뷰어 컴팩트 모드 깜빡임 수정
- 기존 단일 `90px` 경계에서 컴팩트 모드를 켰다 끄던 방식 제거
- `130px 이상`에서 컴팩트 진입, `55px 이하`에서 일반 모드 복귀하도록 히스테리시스 적용
- 헤더 자체 높이가 바뀌면서 스크롤 위치가 경계값을 반복 통과하던 현상 방지
- 뷰어를 열거나 닫을 때 컴팩트 상태값을 명시적으로 초기화

### 파비콘 수정
- 기본 파비콘을 data URI 대신 실제 `/favicon.svg` 정적 파일로 제공
- `rel=icon`과 `rel=shortcut icon`을 함께 설정
- v6.30 기본 data URI가 KV에 저장돼 있는 경우 자동으로 `/favicon.svg`로 대체
- 관리자가 지정한 파비콘 URL은 설정 변경 시점 값을 쿼리에 붙여 브라우저 캐시 갱신 유도
- 관리자 파비콘 입력 기본값도 `/favicon.svg`로 표시

### 메인 컴팩트 헤더 전환 시점 조정
- 고정된 `window.scrollY > 130` 기준 제거
- 실제 메인 상단 검색창 위치를 기준으로 전환
- 원래 검색창이 화면에서 거의 사라진 뒤에만 컴팩트 검색 헤더 활성화
- 다시 위로 올라갈 때는 충분히 검색창이 보인 뒤 일반 헤더로 복귀
- 진입/해제 기준을 다르게 두어 헤더 높이 변화로 인한 깜빡임 방지

## v6.30

### 사이트 이름 / 파비콘 설정
- 관리자 `사이트 설정`에서 사이트 이름 직접 변경 가능
- 사이트 이름은 브라우저 탭 제목과 메인 좌측 브랜드명에 함께 반영
- 관리자에서 파비콘 이미지 URL 직접 설정 가능
- 파비콘은 `https://`, `/` 경로, `data:image` 형식 지원
- 파비콘 값을 비워두면 기본 고양이 아이콘 사용
- 기존 상단 좌측 고양이 로고 아이콘 자체는 유지

### 관리자 설정 화면 정리
- 기존 `설명 문구` 입력 영역 삭제
- 관리자 설정 영역을 `사이트 이름 / 파비콘 / 서브 타이틀 / 메인 타이틀`만 남기도록 단순화
- 기존 공개 메인 화면에서 사용하지 않던 subtitle 설정 저장도 제거

### 메인 화면 컴팩트 고정 검색 헤더
- PC와 모바일 모두 메인 화면 스크롤 130px 이후 헤더가 컴팩트 모드로 전환
- 컴팩트 모드에서 상단 헤더 중앙에 검색창 고정 표시
- 기존 큰 검색창과 컴팩트 검색창의 검색어를 실시간 동기화
- 컴팩트 검색창에서도 제목/작성자 검색 및 검색어 삭제 가능
- 리더 본문을 열면 컴팩트 헤더 모드 해제하여 읽기 화면과 겹치지 않음
- 모바일에서는 공간 확보를 위해 컴팩트 상태에서 브랜드 텍스트를 숨기고 작은 화면에서는 북마크/최근조회 헤더 아이콘도 숨김
- 기존 검색/필터 데이터 처리 방식은 그대로 사용하여 추가 서버 요청 없음

## v6.29

### 메인 목록 개인 필터
- 로그인 사용자용 `북마크만` 빠른 필터 추가
- 로그인 사용자용 `읽는 중` 빠른 필터 추가
- `읽는 중`은 진행률 1~94%이면서 읽음 완료가 아닌 작품만 표시
- 두 필터는 기존 인물조합/분량/검색 필터와 함께 조합해서 사용 가능
- 비로그인 상태에서 개인 필터를 누르면 로그인 모달 표시
- 검색·필터 초기화 시 개인 필터도 함께 해제

### 최근 읽던 작품 바로가기
- 로그인 상태에서 최근 읽던 미완독 작품 1개를 상단에 작은 `이어보기` 버튼으로 표시
- 최근 조회/진행 업데이트 시간을 기준으로 가장 최근 작품 선택

- 설정 파일은 패치 ZIP에 포함하지 않음

## v6.19

### 810KB 이상 긴 파일 렌더링 방식 변경
- 프로그래스바 종료 시간을 늦추는 방식만으로 해결되지 않던 긴 파일 멈춤 현상을 구조적으로 수정
- Google Drive + KV 본문 구조는 그대로 유지하고 R2/유료 저장소는 사용하지 않음
- 810KB 이상 파일은 전체 본문을 한 번에 DOM에 렌더링하지 않도록 변경
- 긴 본문을 브라우저 메모리에서 약 180,000자 단위로 나눔
- 처음에는 앞쪽 1~2개 조각만 화면에 렌더링하여 scrollbar를 빠르게 생성
- 사용자가 실제로 아래로 읽어 내려갈 때 다음 1~2개 조각을 자동 렌더링
- 따라서 프로그래스바가 사라진 뒤 브라우저가 전체 수백만 자 레이아웃을 다시 계산하며 멈추는 구간을 제거
- 추가 본문은 이미 다운로드된 텍스트를 브라우저 메모리에서 표시하므로 Google Drive/KV 추가 요청이 발생하지 않음
- 긴 파일 읽기 위치는 `chunk 번호 + chunk 내부 위치` 기준으로 저장하도록 보완
- 기존 퍼센트 기반 읽기 기록도 이어보기 시 긴 파일의 적절한 chunk 위치로 변환
- 짧은 파일은 기존 전체 렌더링 방식을 유지

- 정상 형식으로 파싱되는 Google Drive 파일명은 수동 수정값보다 항상 우선하도록 변경
- 정상 파일에 남아 있는 오래된 KV override가 있어도 사용자 화면에서는 적용하지 않도록 개선
- `Drive 다시 읽기` 시 정상 파일에 연결된 기존 수동 override를 KV에서 자동 제거
- 이전 Drive 파일명과 현재 파일명을 비교하여 파일명 변경 여부를 동기화 결과에 기록
- 관리자 `수정 완료` 개수는 실제로 유효한 수동 수정값만 계산하도록 보정

### 파일명 우선순위
1. 현재 Google Drive 파일명이 정상 형식이면 Drive의 제목/작성자 사용
2. 현재 Drive 파일명이 비정상인 경우에만 관리자 수동 수정값 사용
3. 수동 수정값도 없으면 원본 파일명 기반 임시 정보 사용

## 패치 배포 원칙

앞으로 각 패치 ZIP에는 다음을 포함합니다.

- 실제 변경된 소스 파일
- `README.md` 변경 이력

다음 파일은 사용자가 명시적으로 요청하지 않는 한 패치 ZIP에 포함하지 않습니다.

- `wrangler.toml`
- `.env`, `.dev.vars`
- `.gitignore`
- 서비스 계정 / 토큰 / 인증정보 관련 파일
- 기타 Cloudflare 배포 설정 파일
